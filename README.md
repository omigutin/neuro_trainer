# neuro_trainer

Обучение нейросетей Ultralytics YOLO через веб-интерфейс: классификация, детекция, сегментация,
ключевые точки (pose) и повёрнутые рамки (OBB). Модели YOLO26, YOLO11, YOLO12, YOLOv10, YOLOv9, YOLOv8
или свой файл `.pt` для дообучения.

## Требования

- Python 3.10–3.13 (проверено на 3.12).
- [Poetry](https://python-poetry.org/docs/#installation) 1.8+.
- Для обучения на видеокарте — NVIDIA GPU и драйвер с поддержкой CUDA 12.6 (`nvidia-smi` показывает `CUDA Version: 12.6` или выше).

## Установка

Из корня проекта:

```powershell
poetry lock --no-update      # только после изменения pyproject.toml; в Poetry 2.x — просто: poetry lock
poetry install -E web
```

- `-E web` — ставит FastAPI, Uvicorn и Jinja2 для веб-интерфейса. Без него доступна только библиотека.
- Виртуальное окружение создаётся в `.venv` внутри проекта (`poetry.toml`).
- torch и torchvision ставятся из репозитория PyTorch со сборкой под CUDA 12.6 (`[[tool.poetry.source]] pytorch-cuda` в `pyproject.toml`). На PyPI для Windows есть только CPU-сборка.

Проверка, что torch видит видеокарту:

```powershell
.venv\Scripts\python.exe -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

Ожидается `2.7.1+cu126 True`. Если `+cpu` или `False` — обучение пойдёт на процессоре.

## Запуск

```powershell
.venv\Scripts\python.exe run_web.py
```

Откроется браузер с адресом `http://127.0.0.1:8765/`. Параметры: `--port 9000` — другой порт, `--no-browser` — не открывать браузер.
Сервер слушает только этот компьютер (127.0.0.1): интерфейс открывает файлы и запускает процессы локально.

В PyCharm — интерпретатор `.venv\Scripts\python.exe`, скрипт `run_web.py`, рабочий каталог — корень проекта.

## Как пользоваться

1. **Модель и источник.**
   - Стандартная: линейка → задача → размер (n — самая быстрая, x — самая точная). Веса скачиваются при первом запуске в `configs/weights/`.
   - Свой файл (.pt): «Выбрать…» → задача и классы читаются из файла.
     Режим «Дообучение» — новое обучение от этих весов; «Продолжить прерванное» — выбрать `weights/last.pt` прерванного рана.
2. **Датасет:** `data.yaml` (детекция, сегментация, pose, OBB) или папка с `train/` и `val/` (классификация).
3. **Параметры обучения:** профиль (fast / quality / low_vram) → «Подставить», затем поправить нужное.
   Остальное — в «Доп. настройки» (оптимизация, аугментации, веса потерь). Показываются только параметры, применимые к задаче.
4. Наведите курсор на любое поле — всплывёт подсказка, что делает параметр.
5. «Проверить на датасете» — прогон без обучения; «Старт» — обучение. Ход — на вкладке «Прогресс»:
   графики метрик и потерь по эпохам, вывод процесса. «Стоп после эпохи» — завершить с сохранением весов, «Прервать» — немедленно.

Настройки сохраняются автоматически (`configs/last_session.yaml`). Свои наборы настроек — «Сохранить» / «Загрузить» внизу формы (`configs/presets_user/`).

## Где что лежит

| Путь | Что |
|---|---|
| `runs/<classify\|detect\|segment\|pose\|obb>/<run>/` | Результаты: `weights/best.pt`, `weights/last.pt`, `results.csv`, графики Ultralytics |
| `runs/.../<run>/train_metrics.jsonl` | Метрики по эпохам (график на вкладке «Прогресс») |
| `runs/.../<run>/train.log` | Вывод процесса обучения |
| `runs/.../<run>/final_metrics.json`, `val_metrics.json` | Итоговые метрики обучения / проверки |
| `runs/.../<run>/job_spec.json`, `job_status.json` | Параметры запуска и его итог |
| `configs/presets/<cls\|det\|seg\|pose\|obb>_<profile>.yaml` | Профили гиперпараметров |
| `configs/weights/` | Кэш стандартных весов |

## Для разработки

- Параметры обучения описаны в одном месте — `src/neuro_trainer/params_catalog.py` (тип, группа, диапазон, задачи, подсказка).
  Новый параметр Ultralytics добавляется одной записью: форма, проверка и передача в `train()` подхватят его сами.
- Обучение выполняется в отдельном процессе (`neuro_trainer.job_worker`), веб-сервер им управляет через `JobManager`.
- Подключение к другому FastAPI-приложению: `from neuro_trainer.web import mount; mount(app, "/trainer")`.
- Тесты: `poetry run pytest` (используют подмену Ultralytics из `tests/fakes`, видеокарта не нужна).

## Частые проблемы

- **`[ERROR] Веб-зависимости не установлены`** — выполнить `poetry install -E web`.
- **Обучение идёт на CPU** — в окружении CPU-сборка torch: `poetry lock --no-update`, `poetry install -E web`, затем проверка из раздела «Установка».
- **Кнопки «Выбрать…» не открывают диалог** — нужен Tkinter (входит в стандартный установщик Python для Windows).
